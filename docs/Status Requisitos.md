# Requisitos Funcionais

## Usuário

| Referência | Descrição                                                                                                                                                                                                                                                                            |    Status    |
| :--------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :----------: |
|  **RF01**  | O usuário deve poder realizar seu cadastro através de nome, e-mail e senha. Após o cadastro, deve ser direcionado para a página inicial (home). Caso já exista um usuário cadastrado com o mesmo e-mail, o sistema deve exibir um pop-up com a mensagem **"Credenciais Inválidas"**. | Concluído |
|  **RF02**  | O usuário deve poder realizar login através de e-mail e senha. Em caso de sucesso, deve ser direcionado para a página inicial (home). Caso o e-mail ou a senha estejam incorretos, o sistema deve exibir um pop-up com a mensagem **"Email ou senha incorretos."**                   | Concluído |
|  **RF03**  | O usuário deve poder realizar logout do sistema ao clicar no botão correspondente. Após o logout, deve ser direcionado para a página de login.                                                                                                                                       | Concluído |
|  **RF04**  | O usuário deve poder acessar a página de médicos e visualizar os médicos disponíveis, seus horários e os tipos de consulta disponíveis, sendo online ou presencial.                                                                                                                  | Iniciado |
|  **RF05**  | O usuário deve poder selecionar um médico e uma data para solicitar uma consulta. Após a solicitação, o sistema deve exibir um pop-up com a mensagem **"Aguardando confirmação de consulta"**.                                                                                       | Iniciado |
|  **RF06**  | Ao solicitar uma consulta pela primeira vez, o usuário deve ser redirecionado para uma página com formulário para cadastro de informações pessoais, como endereço, data de nascimento, peso, altura, entre outras.                                                                   | Não iniciado |
|  **RF07**  | O usuário deve poder confirmar uma consulta com até **1 dia de antecedência** da data prevista.                                                                                                                                                                                      | Não iniciado |
|  **RF08**  | O usuário deve poder cancelar uma consulta com até **1 dia de antecedência** da data prevista.                                                                                                                                                                                       | Não iniciado |
|  **RF09**  | O usuário deve poder acessar a página de histórico de consultas e visualizar suas consultas realizadas e/ou agendadas.                                                                                                                                                               | Não iniciado |
|  **RF10**  | O usuário deve poder acessar e visualizar sua página de perfil.                                                                                                                                                                                                                      | Não iniciado |
|  **RF11**  | O usuário deve poder acessar e visualizar a página inicial (home) do sistema.                                                                                                                                                                                                        | Não iniciado |
|  **RF12**  | O usuário deve poder acessar e visualizar seu histórico de exames.                                                                                                                                                                                                                   | Não iniciado |
|  **RF13**  | O usuário deve poder acessar e visualizar suas receitas e documentos.                                                                                                                                                                                                                | Não iniciado |

## Médico

| Referência | Descrição                                                                                                                                                                                                                                                                                                  |    Status    |
| :--------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------: |
|  **RF14**  | O médico deve poder realizar seu cadastro através de nome, e-mail, CRM, especialidade, senha e UF. O cadastro somente será validado após a aprovação do administrador. Caso já exista um médico cadastrado com o mesmo e-mail, o sistema deve exibir um pop-up com a mensagem **"Credenciais Inválidas"**. | Concluído |
|  **RF15**  | O médico deve poder realizar login através de e-mail e senha. Após o login, deve ser direcionado para a página inicial (home) destinada aos médicos.                                                                                                                                                       | Concluído |
|  **RF16**  | O médico deve poder realizar logout do sistema ao clicar no botão correspondente. Após o logout, deve ser direcionado para a página de login.                                                                                                                                                              | Concluído |
|  **RF17**  | O médico deve poder cadastrar horários disponíveis para consultas, informando o dia, horário e formato da consulta (online ou presencial).                                                                                                                                                                 | Iniciado |
|  **RF18**  | O médico deve poder confirmar uma consulta até **1 dia antes** da data do atendimento.                                                                                                                                                                                                                     | Não iniciado |
|  **RF19**  | O médico deve poder cancelar uma consulta até **1 dia antes** da data do atendimento.                                                                                                                                                                                                                      | Não iniciado |
|  **RF20**  | O médico deve poder, durante ou após a consulta, cadastrar informações do atendimento no prontuário eletrônico do paciente, incluindo dados como peso, altura, temperatura, pressão arterial, motivo da consulta, diagnóstico, prescrição, entre outros.                                                   | Iniciado |
|  **RF21**  | O médico deve poder anexar arquivos relacionados à consulta do paciente, como exames, receitas, atestados e outros documentos.                                                                                                                                                                             | Não iniciado |

## Sistema

| Referência | Descrição                                                                                                                                                               |    Status    |
| :--------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------: |
|  **RF22**  | O sistema deve permitir que os usuários recebam notificações sobre informações das consultas agendadas, incluindo lembretes, alterações e cancelamentos do atendimento. | Não iniciado |
|  **RF23**  | Após 30 dias, um médico com status **inativo** deve ser excluído automaticamente do banco de dados.                                                                     | Não iniciado |

## Administrador

| Referência | Descrição                                                                                                                                      |    Status    |
| :--------: | ---------------------------------------------------------------------------------------------------------------------------------------------- | :----------: |
|  **RF24**  | O administrador deve poder realizar login através de e-mail e senha. Após o login, deve ser direcionado para a página de dashboard do sistema. | Iniciado |
|  **RF25**  | O administrador deve poder confirmar o cadastro dos médicos.                                                                                   | Iniciado |
|  **RF26**  | O administrador deve poder alterar o status do médico entre **ativo** e **inativo**.                                                           | Iniciado |
